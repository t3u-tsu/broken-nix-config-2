# コア・モジュール

システム構成の基盤となるインフラストラクチャ設定です。

## 📂 モジュール構成

- **`user.nix`**: 抽象化されたプライマリユーザーの定義 (`my.user.name`)。
- **`nix.nix`**: Nix の設定、実験的機能、ガベージコレクション、およびバイナリキャッシュ (Substituters) の設定。
- **`networking.nix`**: 基本的なネットワーク構成とホスト名管理。
- **`wireguard.nix`**: WireGuard インターフェースの共通リトライロジックと自動化。
- **`sops.nix`**: 機密情報管理のためのマスター SOPS 構成。
- **`time.nix`**: タイムゾーンと時刻の設定。
- **`default.nix`**: すべてのホストで共通してインポートされるインデックス。
