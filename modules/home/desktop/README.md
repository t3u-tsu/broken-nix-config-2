# Desktop Home Configuration

This directory contains user-level desktop configurations managed via Home Manager.

## 📂 Modules

- **`browsers.nix`**: Declarative configuration for web browsers (Zen Browser, Chromium).
- **`communication.nix`**: Communication tools (Vesktop).
- **`creative.nix`**: Creative tools (GIMP, OBS Studio).
- **`dev-tools/`**: Structured development environment (Neovim, Git tools, AI tools).
- **`locales.nix`**: User-specific language and locale settings.
- **`niri/`**: Niri scrollable-tiling compositor configuration and companion tools.
- **`theme.nix`**: System-wide appearance, GTK/Qt themes (Dracula), and icons.
- **`utils.nix`**: General desktop utilities (VLC, Bitwarden, MangoHud).
- **`xdg.nix`**: XDG MIME associations and desktop integration (default apps).
- **`alacritty.nix`**: Alacritty terminal emulator with Dracula theme.
