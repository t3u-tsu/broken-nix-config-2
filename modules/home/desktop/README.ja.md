# デスクトップ・ホーム設定

このディレクトリには、Home Manager を通じて管理されるユーザーレベルのデスクトップ設定が含まれています。

## 📂 モジュール構成

- **`browsers.nix`**: Web ブラウザ（Zen Browser, Chromium）の宣言的な設定。
- **`communication.nix`**: 通信ツール（Vesktop）。
- **`creative.nix`**: クリエイティブツール（GIMP, OBS Studio）。
- **`dev-tools/`**: 構造化された開発環境（Neovim, Git ツール, AI ツール）。
- **`locales.nix`**: ユーザー固有の言語とロケールの設定。
- **`niri/`**: Niri スクロール型タイルコンポジターと関連ツールの設定。
- **`theme.nix`**: システム全体のルック＆フィール、GTK/Qt テーマ（Dracula）、アイコンの設定。
- **`utils.nix`**: 一般的なデスクトップユーティリティ（VLC, Bitwarden, MangoHud）。
- **`xdg.nix`**: XDG MIME 関連付けとデスクトップ統合（デフォルトアプリ）。
- **`alacritty.nix`**: Dracula テーマを適用した Alacritty ターミナル。
